API Zapp

Documentação completa para integrar com a plataforma Zapp

Visão Geral

A API da Zapp permite que você integre sua aplicação com nossa plataforma de e-commerce. Com a API, você pode gerenciar lojas, produtos, pedidos, clientes e muito mais.

URL Base:
https://api.zapp.com/v1

Versão Atual: 1.0.0

Autenticação

Todos os endpoints requerem autenticação via Bearer Token. Inclua o token no header Authorization.

Obtendo seu token

Faça login no painel de admin e acesse Configurações → Integrações → API para gerar seu token.

curl -H "Authorization: Bearer seu_token_aqui" \
  https://api.zapp.com/v1/stores

Rate Limiting

A API está limitada a 1.000 requisições por hora. Você pode verificar seus limites através dos headers de resposta.

Header Descrição
X-RateLimit-Limit Limite total de requisições por hora
X-RateLimit-Remaining Requisições restantes
X-RateLimit-Reset Timestamp de quando o limite será resetado

Lojas

Endpoints para gerenciar lojas.

GET /stores

Listar todas as lojas do usuário autenticado.

Resposta de Sucesso (200)

{
  "success": true,
  "data": [
    {
      "id": "store_12345",
      "name": "Minha Loja",
      "slug": "minha-loja",
      "description": "Loja online de produtos",
      "created_at": "2024-01-15T10:30:00Z"
    }
  ]
}
GET /stores/{store_id}

Obter detalhes de uma loja específica.

POST /stores

Criar uma nova loja.

Parâmetro Tipo Descrição
name string Obrigatório. Nome da loja
slug string Obrigatório. URL da loja (único)
description string Opcional. Descrição da loja

Produtos

Endpoints para gerenciar produtos.

GET /stores/{store_id}/products

Listar todos os produtos de uma loja.

POST /stores/{store_id}/products

Criar um novo produto.

Parâmetro Tipo Descrição
name string Obrigatório. Nome do produto
price number Obrigatório. Preço do produto
description string Opcional. Descrição do produto
stock integer Opcional. Quantidade em estoque

Pedidos

Endpoints para gerenciar pedidos.

GET /stores/{store_id}/orders

Listar todos os pedidos de uma loja.

GET /stores/{store_id}/orders/{order_id}

Obter detalhes de um pedido específico.

PUT /stores/{store_id}/orders/{order_id}

Atualizar o status de um pedido.

Clientes

Endpoints para gerenciar clientes.

GET /stores/{store_id}/customers

Listar todos os clientes de uma loja.

GET /stores/{store_id}/customers/{customer_id}

Obter detalhes de um cliente específico.

Webhooks

Os webhooks permitem que você receba notificações em tempo real sobre eventos em sua loja.

Eventos Disponíveis

  • order.created - Novo pedido criado
  • order.updated - Pedido atualizado
  • product.created - Novo produto adicionado
  • product.updated - Produto atualizado
  • customer.created - Novo cliente registrado
💡 Dica: Configure seus webhooks no painel de admin em Configurações → Integrações → Webhooks.

Códigos de Erro

Código Significado Descrição
400 Bad Request Requisição inválida ou parâmetros faltantes
401 Unauthorized Token inválido ou expirado
403 Forbidden Você não tem permissão para acessar este recurso
404 Not Found Recurso não encontrado
429 Too Many Requests Limite de requisições excedido
500 Server Error Erro interno do servidor
